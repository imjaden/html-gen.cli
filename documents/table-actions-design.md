# layout-table 操作列按钮功能设计

## 版本

v2.1 (2026-07-12)

## 概述

`layout-table.html` 的 `col.type: 'actions'` 操作列支持三种按钮行为模式：

- **copyKey** — 复制行数据的指定字段到剪贴板（实际功能）
- **hrefKey** — 新标签页打开行数据的 URL（实际功能）
- **desc** — 点击弹出 Toast 展示功能描述（demo/演示模式）

## 按钮配置格式

```typescript
interface ActionButton {
  icon: string;       // Emoji 图标
  label: string;      // 按钮提示文本（title 属性）
  copyKey?: string;   // 复制行数据的指定字段
  hrefKey?: string;   // 打开行数据的 URL 字段
  desc?: string;      // 演示模式：点击弹 Toast 显示功能描述
  class?: string;     // 额外的 CSS class
}
```

优先级：`copyKey` > `hrefKey` > `desc`（只生效第一个匹配的）

## desc 模式行为

当按钮仅配置 `desc`（无 `copyKey`/`hrefKey`）时：

1. 点击按钮 → 底部弹出 Toast
2. Toast 内容：`<icon> <label>: <desc>`
3. 2.5 秒后自动消失
4. 多个 desc 按钮连续点击，Toast 队列显示（最新覆盖）

## 与已有功能的兼容性

- `copyKey` / `hrefKey` 行为不变（向后兼容）
- `desc` 为新增字段，不影响现有配置
- 所有三种模式可在同一操作列混合使用
