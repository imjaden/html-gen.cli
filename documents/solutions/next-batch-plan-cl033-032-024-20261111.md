## CL033（P0）splitGrid 两个 🟡 收口

### 🟡-1 行中 `span:"full"` 与同行兄弟格重叠（真缺陷）

现状（`layout-table.html` 渲染循环）：`full` 恒写 `grid-column:1 / -1`，若该行还有兄弟格，
两者落在同一 grid 行同一批轨道 ⇒ 视觉重叠且无任何提示。评审用例：`[[a, {b, full}]]`。

**采用方案 A（降级为「填满本行剩余轨」）**，理由：
- 数据侧最常见意图是「这一格把剩下的宽度吃掉」，而不是「重开一行」；
- 不引入隐式换行，行数与 `grid` 长度保持 1:1（可预测，几何判据不变）；
- 真要独占整行，写 `[{key, span:"full"}]` 独占一行即可 —— 语义更明确，无需兼容负担。

```js
// 行内：full 且不是该行首格 ⇒ 填满剩余轨；是该行唯一格 ⇒ 1 / -1（等价）
var isAlone = (line.length === 1);
var colSpec = full
  ? (isAlone ? '1 / -1' : colIdx + ' / -1')
  : colIdx + ' / span ' + spanN;
```

拒绝的方案 B（强制独占行）：会让 `grid` 行数与视觉行数错位，`--kv-cols` 计算与 CL031 的
`test_04b`（零空轨）判据都要重定义，收益小于成本。

**新增用例**（`tests/test_split_grid.py`）：
- `test_10_mid_row_full_fills_remainder`：`[[a, {b, full}]]` ⇒ `b.w ≈ gridW - a.w - gap`（±2px），
  且 `b.x > a.x`、两者不重叠、同 `top`；
- `test_11_full_alone_still_spans_all`：`[[{a, full}]]` ⇒ `a.w ≈ gridW`（±2px）（防方案 A 回归）；
- 变异：把 `isAlone ? '1 / -1' : colIdx + ' / -1'` 改回 `'1 / -1'` ⇒ `test_10` 必红。

### 🟡-2 口径订正（`test_01b` 的「判别性」不成立）

  变动），当前稀疏流下与仅写 `grid-column` 等价 —— 评审已复核；
- 本批 commit body 不再出现「判别性」措辞。
