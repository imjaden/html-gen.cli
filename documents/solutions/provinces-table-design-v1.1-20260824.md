## 一、背景与目标

以剧读史/国家速查表等 table demo 之后，新增两个相互关联的数据表：

1. **中国省份速查表**（模板 A 新建）：34 省级行政区，含基础数据 + 与全球国家的交叉关联字段
2. **全球国家速查表补充**：现有 `demos/countries/countries-table.html`（195 国）增加关联省份字段

目标：双表互查——查省份时看到"这个省的面积/人口/GDP 接近哪些国家"，查国家时反向看到"这个国家的面积/人口/GDP 接近哪些省份"，形成数据联想。

## 二、字段设计

## 三、数据口径（决策 1A/2A）

| 数据 | 口径 | 说明 |
|:---|:---|:---|
| 省份面积 | 官方国土面积（万km²） | 含管辖海域不计；新疆 166.49 / 澳门 0.0033 |
| 省份人口 | 七普 2020 常住人口（万人） | 静态权威口径；广东 12601 / 澳门 68 |
| 省份 GDP | 2023 年地区生产总值（亿元） | 最新完整年度；广东 135673 |
| 国家侧面积 | 复用国家表 `area_km2`，**归一化** `area_km2 ÷ 10000 → 万km²` | 换算 ≠ 二次采集，不违背决策 4A |
| 国家侧人口 | 复用国家表 `pop_wan`（万） | 单位与省份一致，直接比较 |
| 国家侧 GDP | 复用国家表 `gdp_yi`（亿美元），**归一化** `gdp_yi × 7.08 → 亿元` | FX = 2023 年均汇率 7.08（人民币/美元，国家统计局口径） |
| 港澳台 | 归"华南"区域 | 按地理大区惯例（用户决策 2A；台湾主流教材亦常归华东，此处以地理相邻华南统列），note 注明"特别行政区/地区，口径与内地有差异" |
| 单位 | 面积统一万km²；GDP 统一亿元 | 不按量级切换单位，保持列内一致 |
| 缺值防护 | 国家表 6 国缺 gdp_yi（也门/南苏丹/厄立特里亚/古巴/朝鲜/梵蒂冈），梵蒂冈缺全部数值 | 匹配脚本 None 防护：该维度不参与匹配，字段留空（与 TC-04 衔接） |

## 四、关联匹配规则（决策 3A）

1. **单位归一化先行**：国家侧按 §三 换算（面积 ÷10000、GDP ×7.08）后再比较，禁止跨单位直接比较（实测不换算 0 命中）
2. **初筛阈值**（脚本自动计算，基于归一化后数值）：
   - 面积：|Δ| ≤ 30%（相对省份值）
   - 人口：|Δ| ≤ 20%
   - GDP：|Δ| ≤ 30%
3. **优先级**（初筛命中多个时排序）：
   a. 地理相邻（接壤/同区域）> b. 知名度高（大众熟悉）> c. 发展阶段相近（人均 GDP 接近）
4. **数量**：每项取 2-3 个（决策 2A）；小省/微国家匹配不到 2 个时允许 1 个或留空
5. **双向机制（单方向匹配 + 反向回填）**：省份表 34 省 × 3 项由匹配脚本一次计算（以省份值为基准）；国家表 3 列反向回填同对（国家 A 在省份 X 的"面积相近国家"中 → X 写入国家 A 的"面积相近省份"）。保证两表语义互证；匹配不到则留空。
6. **真实命中对示例（已按 2023/七普数据实测在阈值内）**：
   - 面积：广东 17.97 万km² ↔ 柬埔寨 18.10 / 乌拉圭 17.62 / 叙利亚 18.52
   - 人口：广东 12601 万 ↔ 墨西哥 12846 / 日本 12452
   - GDP：广东 135673 亿（归一化） ↔ 韩国 / 西班牙 / 墨西哥
7. **人工复核**：脚本初筛结果落盘后，ops 复核每省 3 项，修正明显不合理（如微国家匹配、知名度低、发展阶段悬殊）；复核后实体名与表内精确一致（防 typo 断链）

## 五、数据源策略（决策 4A）

- ops 闭环内先备数据源：34 省基础数据（面积/人口/GDP）+ 匹配脚本
  - **匹配脚本**：`scripts/provinces-match.py`（读 `data/_countries-data.json` ↔ 省份基础表，按 §三 归一化 + §四 规则生成双向关联草稿；None 防护 + 实体名交集校验）
  - 落盘：`data/_provinces-source.json`（草稿，不入 git，dev 实施中间产物）
  - **gitignore 防护**：`_provinces-source.json` 加入 `.gitignore`（防误提交）
  - ops 人工复核清单：逐省确认 3 项关联合理性
- dev 实施时读数据源，组装 `_provinces-data.json` + 国家表 3 列 + 生成物 + 测试

## 八、扩展方向（决策 3D：仅记录，不入本轮表）

1. 接壤关系双向列（省份接壤国家 ↔ 国家接壤省份）——地理意义最强，下轮优先
2. 人均 GDP（省份人均 ↔ 国家人均，发展阶段可比）
3. 人口密度计算列
4. 气候/温度带双向对照
5. 省会 ↔ 首都经纬度（distance/split 定位复用）
6. 时区对照
7. 民族构成对照（国家表已有"主要民族"列）
8. 世界遗产/5A 景区数量
9. 车牌代码/电话区号 ↔ 国家 ISO 代码
10. 最高峰/地形对照
11. 海岸线（沿海省份 ↔ 沿海国家）
