## 二、重新设计的商业分析菜单

### 设计原则

1. **纵向 = 主体维度**（左侧栏 Tab）：公司分析的核心视角
2. **横向 = 子主题**（点击左侧后右侧顶部）：该维度下的细分话题
3. **商业分析导向**：以售前架构师视角看一家公司

### 新菜单结构

```
┌────────────────────────────────────────────────────────────────┐
│  横向 Tab（4组）                                                │
│  [🏢 公司概况] [📊 经营分析] [🧩 产品体系] [🔧 开源生态]       │
├────────────────────────────────────────────────────────────────┤
│  纵向  │                                                       │
│  ──────│─────────────────────────────────────────────────────── │
│  概述   │  · 公司画像                                          │
│         │  · 发展历程                                          │
│         │  · 融资与估值                                        │
│  ──────│─────────────────────────────────────────────────────── │
│  经营   │  · 商业模式与客户                                    │
│  分析   │  · 市场竞争格局                                      │
│         │  · 发展前景与战略                                    │
│         │  · 风险与挑战                                        │
│  ──────│─────────────────────────────────────────────────────── │
│  产品   │  · 产品矩阵总览（OSI×IPDRR）                         │
│  体系   │  · 核心产品解析                                      │
│         │  · 技术架构                                          │
│         │  · 交付体系（Agent/MCP/CLI/FDE）                     │
│  ──────│─────────────────────────────────────────────────────── │
│  开源   │  · 开源项目总览                                      │
│  生态   │  · Top 10 明星项目                                   │
│         │  · 开源战略解读                                      │
└────────────────────────────────────────────────────────────────┘
```

### 与原始菜单的差异

| 维度 | 原始（面试导向） | 新设计（商业分析导向） |
|:---|:---|:---|
| **视角** | 面试者（我需要知道什么） | 售前架构师（这家公司怎么样） |
| **Tab 1** | 公司经营 | 🏢 **公司概况**（精简聚焦） |
| **Tab 2** | 产品体系 | 📊 **经营分析**（新增商业模式/客户/风险） |
| **Tab 3** | 知识迁移（安全知识） | 🧩 **产品体系**（保留并深化技术架构） |
| **Tab 4** | 学以致用（SLA监控） | 🔧 **开源生态**（从产品体系拆出） |
| **维度标记** | 理解/能讲/能输出（面试深度） | 不适用 → 改为信息类型标记 |

## 四、与 C 型模板的映射

C 型模板（`layout-knowledge.html`）的数据模型：

```json
{
  "title": "条目名称",
  "group": "类目名",       // 对应横向 Tab
  "section": "子分类",     // 对应纵向分组
  "badge": "标记",         // 信息类型: 概览/深度/数据
  "content": "<p>HTML</p>"
}
```

横向 Tab = `group` → 公司概况 / 经营分析 / 产品体系 / 开源生态
纵向分组 = `group` + `section` → 同一 group 下按 section 分组
条目标记 = `badge` → 概览 / 深度 / 对比 / 数据
