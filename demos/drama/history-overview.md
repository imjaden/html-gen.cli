# 中国历史 · 概述

## 朝代脉络

唐、宋、元、明、清五朝横跨近 1300 年，从盛唐的万邦来朝到清末的积贫积弱，构成了中华文明最具戏剧性的历史长卷。

## 代表影视剧

| 朝代 | 代表作品 | 核心主题 |
|:---|:---|:---|
| 唐 | 《长安十二时辰》《狄仁杰》系列 | 盛世危机、刑侦探案 |
| 宋 | 《清平乐》《大宋少年志》 | 文治天下、少年热血 |
| 元 | 《成吉思汗》《忽必烈传奇》 | 草原帝国、民族融合 |
| 明 | 《大明王朝1566》《锦衣之下》 | 朝堂博弈、反腐肃贪 |
| 清 | 《雍正王朝》《甄嬛传》 | 勤政改革、宫闱权斗 |
