# 云智慧 · 竞争格局

## AIOps 赛道玩家

| 厂商 | 定位 |
|:---|:---|
| 云智慧（博云） | 全栈智能运维（监控/APM/压测/事件/AIOps） |
| 听云 | 应用性能监控（APM） |
| 博睿数据 | 应用性能管理 + 智能运维 |
| 基调网络 | 网站/移动性能监测 |

## 云智慧的差异化

1. **产品广度**：12 大产品系列覆盖监控→管理→智能全链路（对比 APM 单点厂商）
2. **Gartner 认可**：连续 3 年入选 Gartner AIOps 研究报告（中国区代表）
3. **产学研**：清华大学智能运维研究中心
4. **先发**：2009 年起步的国内最早监控 SaaS 之一

## 风险

- 赛道竞争激烈（APM 厂商 + 云厂商自带监控 + 开源 Prometheus 生态）
- 大客户定制化成本高
