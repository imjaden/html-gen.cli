# 云智慧 · 开源项目

## GitHub 组织

- **CloudWise-OpenSource**：[github.com/orgs/CloudWise-OpenSource](https://github.com/orgs/CloudWise-OpenSource/repositories)
- 云智慧开源运维工具集：监控、巡检、故障诊断等场景的工程化组件
